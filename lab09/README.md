последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.* 

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

**Решение.** ([6/task6.py](6/task6.py))

```python
def gen(n):
    yield n
    while n != 1:
        n = n // 2 if n % 2 == 0 else 3 * n + 1
        yield n
```

**Объяснение:**
Генераторная функция использует `yield`, чтобы отдавать значения по одному по мере итерации. Сначала возвращается исходное число `n`, затем в цикле до достижения единицы вычисляется следующий член последовательности Коллатца (`n // 2` для четного и `3 * n + 1` для нечетного).

**seq** *будет задавать последовательность из каждого второго элемента* **seq**.

```
def every_other(seq):
    ...
```
*Ниже приведены примеры использования генератра.*
```
>>> print (*every_other([10, 20, 30, 40, 50]))
10 30 50
>>> print(*every_other(range(10)))
0 2 4 6 8
>>> print(*every_other(iter(range(10))))
0 2 4 6 8
>>> print(sum(every_other(map(int, input().split()))))
2 5 11 3 8

```

**Решение.** ([7/task7.py](7/task7.py))

```python
def every_other(seq):
    for i, item in enumerate(seq):
        if i % 2 == 0:
            yield item
```

**Объяснение:**
Срез `seq[::2]` не работает для итераторов вроде `iter(range(10))` или `map(...)`, так как они не поддерживают индексацию. Использование `enumerate(seq)` позволяет перебрать любую итерируемую последовательность и выдавать через `yield` только элементы с четными индексами (`0, 2, 4, ...`).

### Задание 10 **(1)**
*Какие из указанных функций и методов Python соответствуют определению чистых функций?
В случае отрицательного ответа требуется дать пояснение.*

* **file.readline** — **не чистая**. Зависит от внешнего состояния (содержимого файла и позиции курсора чтения) и имеет побочный эффект (сдвигает позицию чтения в файле).
* **len** — **чистая** (для встроенных контейнеров). Не изменяет переданный объект и при одинаковых входных данных всегда возвращает один и тот же результат.
* **list.append** — **не чистая**. Имеет побочный эффект: модифицирует (мутирует) исходный список на месте и возвращает `None`.
* **sum** — **чистая**. Не изменяет переданную последовательность и детерминированно возвращает сумму элементов.
* **sorted** — **чистая**. Создает и возвращает новый отсортированный список, не изменяя исходный объект.
* **list.sort** — **не чистая**. Имеет побочный эффект: сортирует список на месте (мутирует его) и возвращает `None`.
* **random.randint** — **не чистая**. Недетерминирована (при одинаковых аргументах возвращает разные случайные числа) и изменяет внутреннее состояние генератора случайных чисел.
* *Разворот списка:*
```python
def rev(x):
    return x[::-1]
```
**Чистая.** Срез `x[::-1]` создает новый список, не изменяет аргумент `x` и не зависит от внешнего состояния.
* *Выбор нескольких элементов из хвоста списка:*
```python
tail_len = 3
def tail(x):
    return x[-tail_len:]
```
**Не чистая.** Зависит от внешней глобальной переменной `tail_len`: при ее изменении функция для того же аргумента `x` вернет другой результат.

**Решение.** ([dop1/dop1.py](dop1/dop1.py))

Декоратор в Python — это функция высшего порядка, которая принимает другую функцию и расширяет ее поведение без изменения ее исходного кода. Синтаксис `@toint` перед определением `def add(...)` эквивалентен `add = toint(add)`.

```python
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper

@toint
def add(a, b):
    return a + b

@toint
def area(width, height):
    return width * height

print(add('15', '27'))   # 42
print(area('4', 5.9))    # 20
```

### Задание 3 **(5)**

*Напишите рекурсивную функцию для нахождения* **n**-го *числа Фибоначчи.*

*Функция обязательно должна работать с достаточно большими числами, например* **n = 1000** *и не 
должна использовать библиотечные функции и методы.*

**Решение.** ([dop3/dop3.py](dop3/dop3.py))

```python
def fib(n):
    def _fib_pair(k):
        if k == 0:
            return (0, 1)
        a, b = _fib_pair(k // 2)
        c = a * (2 * b - a)
        d = a * a + b * b
        if k % 2 == 0:
            return (c, d)
        else:
            return (d, c + d)

    return _fib_pair(n)[0]
```

**Объяснение:**
Обычная линейная рекурсия для `n = 1000` превышает стандартный лимит глубины стека Python (`1000`). Метод **быстрого удвоения (Fast Doubling)** использует тождества:
* $F(2k) = F(k) \cdot (2F(k+1) - F(k))$
* $F(2k+1) = F(k)^2 + F(k+1)^2$

Глубина рекурсии составляет всего $O(\log_2 n) pprox 10$ вызовов для $n = 1000$, алгоритм работает мгновенно и не использует никаких библиотечных функций или методов.

### Задание 4 **(9)**

*Напишите функцию* **fastpow**, *которая будет создавать лямбда-функцию для быстрого 
возведения в фиксированную степень* **n**. *Например, должен работать следующий код*
```
>>> pow10 = fastpow(10)
>>> print(pow10(2))
1024
```
*Функция* **fastpow** *в этом примере должна строить выражение для быстрого возведения в степень
по стандартному алгоритму* 
* **x^1 = x**;
* **x^{2n} = (x^n) ** 2**; 
* **x^{2n+1}=x*x^{2n}**;

*Например,
для* **n = 10** *может быть получена подобная строка* ```(x*((x**2)**2))**2```. 

*Далее* **fastpow** *будет возвращать лямбда функцию*
```
lambda x: eval(s)
```
*При написании функции* **fastpow** *можно использовать вспомогательные функции.*

**Решение.** ([dop4/dop4.py](dop4/dop4.py))

```python
def fastpow(n):
    def build_expr(k):
        if k == 0:
            return "1"
        if k == 1:
            return "x"
        if k % 2 == 0:
            sub = build_expr(k // 2)
            return f"{sub}**2" if sub == "x" else f"({sub})**2"
        else:
            return f"x*({build_expr(k - 1)})"

    s = build_expr(n)
    return lambda x: eval(s)
```

**Объяснение:**
Вспомогательная рекурсивная функция `build_expr(k)` формирует строковое арифметическое выражение для степени `k` по схеме двоичного возведения в степень (для `n = 10` получается строка `(x*((x**2)**2))**2`). Затем `fastpow` возвращает лямбда-функцию `lambda x: eval(s)`, вычисляющую это выражение для переданного значения `x`.
